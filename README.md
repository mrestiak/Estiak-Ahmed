# Estiak World

A mobile-responsive dark navy and green landing page with falling-snow animation.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — WhatsApp links, live date, and snow animation

## Before publishing
1. Open `script.js`.
2. Replace `8801XXXXXXXXX` in `WHATSAPP_NUMBER` with your WhatsApp number, including country code, digits only.
   - Example format: `4915112345678` for a German number.
3. Save all three files.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `estiak-world`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. Your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/estiak-world/`

The VIP and WhatsApp buttons both open WhatsApp. The number is a placeholder until you replace it.
